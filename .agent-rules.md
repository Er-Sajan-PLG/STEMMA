# Default Agent Behaviors (ALWAYS ON)

## Commits
- **Commit after every logical change** (not at the end)
- **Small, atomic commits** with conventional messages: `type(scope): description`
- **Auto-stage** modified files, **review diff** before commit
- **Never** batch unrelated changes

## Documentation
- **Update docs with every code change** (README, AGENTS.md, specs)
- **Sync docs to implementation** — no drift
- **ADR for any foundational change** (schema, contracts, identity)

## Versioning
- **Bump version** in `schema/VERSION.yaml` on schema/contract changes
- **Regenerate exports** (`python3 scripts/validate.py`) after canonical changes
- **Commit derived artifacts** (exports/, reports/) with source changes

## Validation & CI
- **Run `python3 scripts/validate.py`** after every canonical change
- **Run `python3 scripts/verify_all.py`** before declaring done
- **Fix all ERRORs** (warnings acceptable, errors not)

## Progress Tracking
- **Maintain TODO list** for multi-step work
- **Update TODO status** in real-time
- **Summarize** what was done, what's next, any blockers

## Automation
- **Pre-commit hooks** for format/lint/validate
- **CI pipeline** runs full verify chain
- **Derived artifacts** regenerated and committed automatically

## Code Quality
- **Type hints** on all new functions
- **Error handling** with typed exceptions
- **No secrets** in code or docs
- **Small functions**, clear names, no magic numbers

## Communication
- **Lead with summary** — what changed, why, impact
- **Flag human decisions** explicitly
- **Never assume** — ask when ambiguous

---

**This applies to ALL agents working in this repo. No exceptions.**
