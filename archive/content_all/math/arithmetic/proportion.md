id: stemma:math.proportion
type: concept
name: Proportion
domain: mathematics
status: draft
definition: >-
  An equation stating that two ratios are equal. If a:b = c:d, then a, b, c, d are
  in proportion. This means a/b = c/d, or equivalently a×d = b×c (cross-multiplication).
symbol: null
unit: null
equation: a/b = c/d  ↔  a×d = b×c
examples:
  - "If 3 apples cost $6, then 5 apples cost $10: 3/6 = 5/10"
  - "Map scale: 1 cm : 5 km = 3 cm : 15 km"
common_misconceptions:
  - "Proportions only work with whole numbers (they work with any real numbers)"
  - "Cross-multiplication works for any equation (only for proportions a/b = c/d)"
  - "If a:b = c:d then a:c = b:d (this is true, but must be derived correctly)"
learning_objectives:
  - Set up and solve proportions
  - Apply cross-multiplication correctly
  - Distinguish direct and inverse proportion
  - Solve real-world problems using proportions
real_world_applications:
  - Scale drawings and models
  - Unit conversion (dimensional analysis)
  - Similar triangles in geometry
  - Recipe scaling
key_experiments:
  - "Shadow measurement: use similar triangles to find height of tall objects"
