id: stemma:math.function
type: concept
name: Function
domain: mathematics
status: draft
definition: >-
  A relation between a set of inputs (domain) and a set of possible outputs (codomain)
  where each input is related to exactly one output. Written as f: X → Y or y = f(x).
  The function assigns a unique output f(x) to each input x.
symbol: f(x)
unit: null
equation: null
examples:
  - "f(x) = 2x + 1 (linear function)"
  - "f(x) = x² (quadratic function)"
  - "f(x) = 2ˣ (exponential function)"
common_misconceptions:
  - "Every equation is a function (x² + y² = 1 is not a function of x)"
  - "f(x) means f × x (it means 'f of x', the output of function f at input x)"
  - "A function must have a formula (functions can be defined by tables, graphs, words)"
learning_objectives:
  - Distinguish functions from general relations
  - Identify domain and range
  - Evaluate functions for given inputs
  - Understand function notation f(x)
  - "Compose functions: (f ∘ g)(x) = f(g(x))"
real_world_applications:
  - Mathematical modeling (input → output processes)
  - Computer science (functions in programming)
  - Physics (position as function of time)
  - Economics (cost as function of quantity)
key_experiments:
  - "Function machine: input → rule → output, explore patterns"
