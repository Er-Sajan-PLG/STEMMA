id: stemma:math.linear-function
type: concept
name: Linear Function
domain: mathematics
status: draft
definition: >-
  A function of the form f(x) = mx + b, where m (slope) and b (y-intercept) are constants.
  The graph is a straight line. The rate of change (slope) is constant everywhere.
symbol: f(x) = mx + b
unit: null
equation: f(x) = mx + b
examples:
  - "f(x) = 2x + 3 (slope 2, y-intercept 3)"
  - "f(x) = -x + 5 (slope -1, y-intercept 5)"
  - "f(x) = 4 (constant function, slope 0)"
common_misconceptions:
  - "Linear functions must pass through the origin (only if b = 0)"
  - "Slope is just 'steepness' (it's rate of change: Δy/Δx, with sign)"
  - "Parallel lines have the same y-intercept (same slope, different intercepts)"
learning_objectives:
  - Identify slope and y-intercept from equation, graph, or table
  - Graph linear functions
  - Find equation given slope and a point, or two points
  - Model real-world situations with linear functions
  - Compare linear vs non-linear relationships
real_world_applications:
  - Constant rate problems (speed, hourly wage)
  - Depreciation (straight-line)
  - Supply/demand curves (linear approximation)
  - Temperature conversion (C = 5/9(F - 32))
key_experiments:
  - "Motion at constant speed: distance vs time graph is linear"
