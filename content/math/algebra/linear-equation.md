id: stemma:math.linear-equation
type: concept
name: Linear Equation
domain: mathematics
status: draft
definition: >-
  An equation in which the highest power of the variable is 1. In one variable: ax + b = 0 (a ≠ 0).
  In two variables: ax + by + c = 0. The graph of a linear equation in two variables is a straight line.
symbol: null
unit: null
equation: ax + b = 0  (one variable) |  ax + by + c = 0  (two variables)
examples:
  - "2x + 3 = 7 (solution: x = 2)"
  - "y = 2x + 1 (slope-intercept form)"
  - "3x - 4y = 12 (standard form)"
common_misconceptions:
  - "All equations with x and y are linear (x² + y = 1 is not linear)"
  - "The slope is always the coefficient of x (only in y = mx + b form)"
  - "Parallel lines have the same y-intercept (they have the same slope, different intercepts)"
learning_objectives:
  - Solve linear equations in one variable
  - Graph linear equations in two variables
  - Find slope and intercepts from equations and graphs
  - Convert between standard, slope-intercept, and point-slope forms
  - Solve systems of two linear equations (substitution, elimination, graphical)
real_world_applications:
  - Rate problems (distance = rate × time)
  - Cost models (fixed cost + variable cost)
  - Supply and demand curves in economics
  - Break-even analysis
key_experiments:
  - "Graphing with technology: explore how slope and intercept change the line"
