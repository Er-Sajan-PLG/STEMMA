name: Variable

definition: >-
  A symbol (usually a letter) that represents an unknown or changeable quantity.
  Variables allow generalization of arithmetic relationships and the formulation
  of algebraic expressions and equations.
symbol: x, y, z, t, ...
unit: null
equation: null
examples:
  - "In 2x + 3 = 7, x is the unknown variable"
  - "In A = πr², r is the variable radius"
  - "In y = 2x + 1, x and y are variables with a functional relationship"
common_misconceptions:
  - "A variable has only one value (it can represent many values or an unknown specific value)"
  - "Different letters must represent different numbers (x and y can be equal)"
  - "Variables are only for algebra (they appear in formulas, functions, statistics)"
learning_objectives:
  - Understand variables as placeholders for numbers
  - Distinguish between independent and dependent variables
  - Use variables to express patterns and relationships
  - Evaluate expressions by substituting values for variables
real_world_applications:
  - Formulas in physics, chemistry, economics
  - Computer programming (variables store data)
  - Scientific modeling (parameters that vary)
