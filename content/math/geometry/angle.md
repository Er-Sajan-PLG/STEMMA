type: concept
name: Angle
domain: mathematics
status: draft
definition: >-
  The figure formed by two rays (sides) sharing a common endpoint (vertex).
  Measured in degrees (°) or radians (rad). One full rotation = 360° = 2π rad.
symbol: ∠, θ, α, β, ...
unit: degree (°), radian (rad)
equation: null
examples:
  - "Right angle = 90° = π/2 rad"
  - "Straight angle = 180° = π rad"
  - "Acute angle < 90°, Obtuse angle > 90° and < 180°"
common_misconceptions:
  - "Angle size depends on ray length (it depends only on rotation between rays)"
  - "Degrees and radians are the same (360° = 2π rad, so 1 rad ≈ 57.3°)"
  - "Negative angles don't exist (negative = clockwise rotation)"
learning_objectives:
  - Measure and draw angles using a protractor
  - Classify angles (acute, right, obtuse, straight, reflex)
  - Convert between degrees and radians
  - Identify complementary (sum = 90°) and supplementary (sum = 180°) angles
  - "Use angle properties: vertically opposite, alternate, corresponding"
real_world_applications:
  - Navigation (bearings)
  - Architecture and construction
  - Optics (angle of incidence = angle of reflection)
  - Robotics (joint angles)
key_experiments:
  - "Protractor practice: measure angles in everyday objects"
