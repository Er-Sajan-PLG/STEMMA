🧠 AI-Assisted Semantic Acquisition Pipeline — Accepted Proposal Implementation

    
Use AI early for semantic understanding. Trust AI late only through independent verification and explicit canonicalization. SOURCE → Deterministic acquisition → Evidence-preserving extraction → AI-assisted semantic extraction → Structured candidate claims → Independent verification → Conflict analysis → Human review → Explicit canonicalization → STEMMA canonical. LLM is extractor/interpreter, not authority.

How scaling works + LLM when necessary + frontier model selection

    

      

        
📈 Scaling — deterministic, evolvable templates

        
    
          
  1. Registry-driven: schema/template-registry.yaml defines domains (physics, chemistry, biology, math), subdomains, entity types, extraction regex rules — add new domain without code: python3 scripts/evolvable_template.py --evolve --new-domain chemistry
    2. 
          
  2. Deterministic extraction: Regex patterns like Length:\s*(.+) extract entities from PDF text — no LLM, scales to 1000s of PDFs
    3. 
          
  3. Exact SI fallback: If PDF has exact (e.g., "Exact: c=299,792,458"), use it. If not, fallback to constants in registry (c, h, ΔνCs, e, k, N_A, K_cd) — still deterministic, no LLM
    4. 
          
  4. Evolvable: Templates have placeholders {definition}, {symbol}, etc. — evolve by editing YAML, not code
    5. 
        

      

      

        
🤖 LLM only when PDF missing exact SI + model selector like DeepSeek harness (local + frontier models)

        
    
          
  1. When needed: If PDF text doesn't contain exact SI definition with fixed constants (e.g., textbook says "Length is distance" without "Exact: c=..."), then LLM fallback fetches standard definition from SI Brochure/NIST
    2. 
          
  2. Frontier models: In Settings, choose any frontier: DeepSeek R1 (reasoning), DeepSeek V3, Claude 3.5 Sonnet, Claude 3 Opus, GPT-4o, Gemini 2.5 Pro, Llama 3.3 70B — via OpenRouter, NVIDIA NIM, or custom endpoint
    3. 
          
  3. Custom model: Type any model id in Custom Model input — your fine-tuned, local Llama, or frontier — system uses it if provider supports
    4. 
          
  4. Model selector like DeepSeek harness: Search bar, category tabs (Frontier, Reasoning, Free, Custom), model cards with provider, free badge, capabilities — standard inference window
    5. 
          
  5. Even LLM requires HITL: LLM output → markdown preview → human explicitly edits → audit logs candidate_edited by human → stage → validate (including hitl_check) → canonical
    6.
